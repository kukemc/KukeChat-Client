2.0.4 更新内容包括：
- 新增「续火花」：和好友每天互相发消息就能续上火花，连续天数越长等级越高，熄灭后 3 天内还能重燃
- 群公告全面升级：发布或修改公告会在群里发一张公告卡片，支持多张图片、弹窗展示、确认收到、置顶和发送给新成员
- 手机端可以发布、编辑、删除群公告，还能查看谁确认了公告
- 群文件改为后台下载，通知栏和文件卡片上都有进度条，下载完点「打开」直接打开或安装
- 群文件里的视频可以直接在 App 里播放
- 设置里补上了戳一戳、在线状态、复制主页链接、自定义强调色等选项
- 点机器人的头像、名字或名片，可以直接进入机器人详情
- 修复下载群文件时一直卡在 0%、下载面板关不掉的问题
