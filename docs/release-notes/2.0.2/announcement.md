2.0.2 更新内容包括：
- 新增接龙红包：领取时会自动发出发红包的人设定的一句话
- 新增专属红包：在群里指定一个人，只有他能领
- 聊天里有没领的红包时，右上角会提示，点一下就跳过去
- 进群时有很多未读消息，右上角会提示「N 条新消息」，点一下跳到第一条未读
- 发消息、发图片会马上显示在聊天里，发送失败可以点击重发
- 可以一次选多张图片，粘贴截图也会先预览确认再发
- 多选消息可以按住鼠标拖动框选，也能「选到这里」或按 Shift 连选
- 表情回应多了很多表情
- 群文件支持文件夹了（Pro+ 和 MAX 群），还能直接把文件拖进文件夹
- 下载群文件时能看到进度，下完可以直接在文件夹里打开
- B 站视频链接会显示成卡片
